# OMNICON — Ideas / Out of scope

A running list of features and ideas deferred out of the current mockup scope.

## Review screen

- **Referenced span** — let the reviewer attach a specific transcript span to a
  piece of feedback (e.g. quote the exact line "Priya owns mobile rollout") so
  OMNICON knows precisely what the correction refers to. Originally prototyped as
  a static quote card on the Review screen; removed for now. When revisited it
  should be an interactive control: select a span from the transcript, attach it
  to the feedback, and remove it. (Removed Jun 13, 2026.)
